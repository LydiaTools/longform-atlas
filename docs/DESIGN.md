# Design decisions

**Concept:** an editorial route map. The audience is a creator building a recognizable IP across multiple overseas platforms, not an SEO dashboard operator watching invented scores. The main pane follows IP positioning → article plan and brief → sources → draft; the left rail stays visually connected to that route.

**Palette:** deep atlas blue `#17404c`, pale map ground `#f7f5ec`, sea-glass `#e1e9e4`, coral annotation `#d36b4d`, line `#b7c8bf`.

**Type:** Georgia for the main editorial title and section names; Avenir Next and Chinese system sans-serif for form controls.

**Layout:** wide writing sheet with a slim route rail. The IP sheet has a paper-tone thesis block and plan items read as editorial ledger rows. On narrow screens the rail becomes a compact horizontal route marker and the two-column forms stack.

**Memorable detail:** the route from creator positioning to a set of distinct platform angles is the visual navigation. No charts, fake performance figures or generic marketing cards.

**Limits:** the structure check is deterministic and cannot verify facts or predict search ranking. The local outline is a scaffold; the optional model creates the prose.
